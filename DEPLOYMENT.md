# Инструкция по развертыванию на GitHub Pages

## Шаги для публикации веб-страницы:

### 1. Создание репозитория на GitHub
1. Перейдите на [github.com](https://github.com)
2. Нажмите кнопку "New repository" (зеленая кнопка)
3. Заполните поля:
   - **Repository name**: `my-web-page` (или любое другое имя)
   - **Description**: `Моя статическая веб-страница`
   - Выберите **Public** (обязательно для бесплатного GitHub Pages)
   - НЕ добавляйте README, .gitignore или лицензию (у нас уже есть файлы)
4. Нажмите "Create repository"

### 2. Подключение локального репозитория к GitHub
Выполните следующие команды в терминале:

```bash
# Добавьте удаленный репозиторий (замените YOUR_USERNAME на ваш GitHub username)
git remote add origin https://github.com/YOUR_USERNAME/my-web-page.git

# Переименуйте ветку в main (если нужно)
git branch -M main

# Отправьте код на GitHub
git push -u origin main
```

### 3. Настройка GitHub Pages
1. Перейдите в ваш репозиторий на GitHub
2. Нажмите на вкладку **Settings** (в верхнем меню)
3. Прокрутите вниз до раздела **Pages** в левом меню
4. В разделе **Source** выберите **Deploy from a branch**
5. Выберите ветку **main** и папку **/ (root)**
6. Нажмите **Save**

### 4. Получение URL вашей страницы
После настройки GitHub Pages (может занять несколько минут):
- Ваша страница будет доступна по адресу: `https://YOUR_USERNAME.github.io/my-web-page`
- GitHub автоматически обновит страницу при каждом push в репозиторий

### 5. Обновление страницы
Для обновления содержимого:
```bash
# Внесите изменения в файлы
# Добавьте изменения в Git
git add .

# Создайте коммит
git commit -m "Update website content"

# Отправьте на GitHub
git push origin main
```
