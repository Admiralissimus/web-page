📋 Инструкции по использованию:

  1. Создайте репозиторий на GitHub:
    • Перейдите на github.com
    • Создайте новый публичный репозиторий
    • Загрузите файлы вашего сайта
  2. Настройте GitHub Pages:
    • Перейдите в Settings → Pages
    • Выберите Source: Deploy from a branch
    • Выберите ветку main и папку / (root)
  3. Получите URL:
    • Ваш сайт будет доступен по адресу: https://ваш-username.github.io/имя-репозитория
  4. Создайте QR код:
    • Введите полученный URL выше
    • Нажмите "Создать QR код"
    • Скачайте и распечатайте QR код
